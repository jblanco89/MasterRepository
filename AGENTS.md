# AGENTS.md

This is not a software project — it is a personal academic repository containing course materials, notes, assignments, and exam solutions from a Master's in Mathematical Engineering and Computer Science at UNIR (Spain).

## Structure

- `Term 1`, `Term 2`, `Term 3`, `Term 4` — course terms
- Each term has subdirectories per course (Applied Numerical Methods, HPC, Python, Stochastic DEs, Optimization, Machine Learning, etc.)
- Common subdirectory pattern: `Assignments/`, `Lectures/`, `Lessons/`, `FinalExam/`

## Notes

- No build, test, or CI tooling exists here
- This repository is read-only academic reference material; do not make substantive edits to course content
